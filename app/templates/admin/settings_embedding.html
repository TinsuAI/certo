OpenRouter + cấu hình mặc định

Hub gọi OpenRouter (OpenAI-compat) để embed mô tả vật tư khi ingest hoặc khi config đổi. Vector lưu trong hub.materials.description_embedding (pgvector, cosine ANN). Lúc tìm "vật tư thay thế" trên trang chi tiết, hệ thống không gọi API — chỉ truy vấn HNSW index trên DB.

Sau khi lưu, dùng Test connection để gọi 1 request thật + xác nhận key + model hợp lệ. Sau đó vào trang Danh mục của từng khách hàng để bấm Cập nhật phân tích AI — phần "Phân tích AI vật tư" ở đầu trang đó.

Cập nhật phân tích AI

Sau khi đổi model hoặc text template ở trên + Lưu, kết quả phân tích AI hiện có của mọi vật tư sẽ không khớp với cấu hình mới. Cập nhật từ trang Danh mục của từng khách hàng.

Vào Khách hàng → <tên khách> → Danh mục. Phần "Phân tích AI vật tư" ở đầu trang có 2 nút:

  • Cập nhật phân tích AI — chỉ làm những vật tư cần cập nhật (tiết kiệm API call, an toàn, idempotent).
  • Làm lại từ đầu — xóa kết quả cũ + làm lại toàn bộ. Dùng khi nghi vector cũ sai hoặc đổi prompt mà không đổi model.

Job chạy nền với trang theo dõi tiến độ riêng. Lịch sử các lần chạy xem ở Khách hàng → Danh mục → "Lịch sử chạy".
