## Decisions made

- **Refactor auth.py into auth/ package** rather than flat sibling module. Cleaner grouping; `from app import auth` API surface unchanged.
- **`visible_clients(user)` returns `None` for unrestricted** (dev/admin), `list[str]` for scoped (manager/staff), `[]` for unauthenticated/staff-with-no-access. Caller filters when not None.
- **Two `require_*` helpers** raise 403 directly to keep route bodies terse. `require_can_view_client`, `require_can_edit_client`. Separate path for `can_edit_client_config` (different gate).
- **`can_create_client` separate helper** because creating ≠ editing config of an existing client.
- **Single-dev invariant via Postgres partial unique index** (`unique on ((1)) where role='dev'`). Catches both API path + raw INSERT path; database is the source of truth.
- **Lock action revokes existing sessions**: `delete from hub.sessions where user_id = ?`. Prevents continued access from already-issued cookies.
- **Self-lock + dev-lock blocked** at route level — cheap defensive check; the user can still bypass via direct DB write (intentional — dev is the operator).
- **Role demotion auto-cleans ACL rows**: switching manager→staff drops `user_managed_clients` rows; switching staff→manager drops `user_client_access` rows. Avoids stale references.
- **Per-client `/staff` tab visibility**: rendered in `_client_nav.html` via `can_manage_staff(client_id)` Jinja closure (binds user from request context). Cleaner than threading a flag through every route.
- **Cross-app SSO deferred**: Foundation (users + roles + ACL + auth-center pattern) is in place. JWT issuer + JWKS + cookie-domain federation belongs to Phase 2 because BCQT/CO consumers don't exist yet — building issuer now would be churn.

## What didn't work

- **First fixture attempt collided with single-dev invariant.** `_make_user(role='dev')` inserted a 2nd dev row → unique violation. Fixed by adding `_seed_admin_as_dev()` helper that reuses the existing seed admin (which migration 008 had already promoted to `dev`).
- **`btn-danger-sm` / `inline-form` / `topnav-chip-link` classes weren't in the existing CSS.** Initially used them in templates, then had to append ~30 lines of CSS to make them render correctly. Should have grep'd first.
- **`grid-table` typo** in initial users.html — actual class is `dh-table`. Replaced via `replace_all`.
